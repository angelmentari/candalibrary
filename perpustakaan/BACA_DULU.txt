========================================================================
PANDUAN INSTALASI SISTEM OTOMASI PERPUSTAKAAN (OPAC PUBLIK + BACKOFFICE)
========================================================================

1. Ekstrak folder `perpustakaan_slims_v2` ke:
   C:\xampp\htdocs\perpustakaan_slims_v2

2. Jalankan Apache & MySQL di XAMPP Control Panel.

3. Import database melalui http://localhost/phpmyadmin:
   - Pilih tab "Import"
   - Pilih file: C:\xampp\htdocs\perpustakaan_slims_v2\database\perpustakaan.sql
   - Klik "Go"

4. Akses Aplikasi di Browser:
   - Halaman Awal (OPAC Katalog Publik & Rincian Isi Buku) :
     http://localhost/perpustakaan_slims_v2/
